
# The Fashion Store — Project Instructions

## Project
Build a premium, production-oriented e-commerce website for
The Fashion Store, Bambalapitiya, Sri Lanka.

## Technology
- Frontend: React, Vite, TypeScript, Tailwind CSS
- Backend: Node.js, Express, TypeScript
- Database: MongoDB, Mongoose
- State management: Zustand
- Data fetching: TanStack Query

## Design Direction
- Premium luxury editorial fashion aesthetic
- Minimalist layouts and refined typography
- Warm neutral colour palette
- Responsive desktop, tablet and mobile layouts
- High-quality fashion photography
- Accessible and intuitive shopping experience

## Business Requirements
- Women's fashion
- Men's fashion
- Kids' fashion
- Plus-size collection
- Product sizes and colours
- Product search and filtering
- Shopping cart and wishlist
- Customer accounts
- Cash on Delivery
- Online payments in Sri Lanka
- Order tracking
- Admin dashboard

## Development Rules
1. Inspect the existing project before changing files.
2. Preserve the existing architecture unless a change is necessary.
3. Use TypeScript and avoid unnecessary `any` types.
4. Keep frontend and backend responsibilities separate.
5. Validate API inputs using Zod.
6. Never trust prices, discounts, stock or payment status
   supplied by the frontend.
7. Never expose secrets in frontend code.
8. Use reusable components and maintainable folder structures.
9. Test changes and run typechecking after implementation.
10. Explain changed files and any manual setup required.

## Workflow
For every feature:
1. Inspect existing implementation.
2. Explain the proposed implementation briefly.
3. Implement the feature.
4. Run relevant checks.
5. Fix errors introduced by the changes.
6. Summarize modified files and remaining work.

Do not replace working project code without a reason.
Do not create fake production payment integrations.
